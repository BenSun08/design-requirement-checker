# Product context

[docs/product-spec.md](docs/product-spec.md) is the authoritative product specification, including draft status, scope, unresolved decisions and acceptance criteria. [docs/ux-spec.md](docs/ux-spec.md) records the prototype experience.

Production technology is Python + PySide6 / Qt Widgets, selected by the owner. The current implementation is an approved desktop skeleton; document ingestion, matching, persistence and Windows distribution remain pending. The browser prototype is a separate disposable mock. See [implementation plan](docs/implementation-plan.md) for the remaining work.
