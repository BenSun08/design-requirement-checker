# UX 规格

[English source](../docs/ux-spec.md)

本文件为同名英文文档的对应中文版本；字段、状态、路径与命令保留原技术标识。

状态：已按用户确认的行为更新。生产 UI 为 Python + PySide6 / Qt Widgets，目标 Windows 10/11 x64，使用者无管理员／安装权限。界面使用简体中文，原始文档使用英文。本目录提供对应中文译本。未修改的本地浏览器原型仅展示早期模拟范围；下述生产要求明确扩展了该范围。

## 信息架构与主要流程

两个一级入口：文档核查、检查项管理。持续显示产品和文档身份；历史原型还要持续显示模拟声明。导入 → 已加载／准备 → 明确运行 → 结果 → 选择异常 → 比较和来源。不增加向导、仪表盘首页、登录或导航层级。只维护一套本地基准，不提供客户／订单模板选择器。

使用紧凑横向标题栏、文档工具栏、汇总／筛选区域及分栏工作区。左侧约 40% 宽度，以密集行展示编号、名称、状态、差异提示；右侧显示选中要求、状态、匹配方法、预期／实际比较、证据解释与原文上下文。窄页脚解释结果适用范围。较窄时上下排列，主要使用场景仍是桌面。

## 历史原型状态

- 空状态：明确 DOCX 拖入／选择区域，说明本地运行，单独提供“使用示例文档”。
- 已加载：显示文件名及“开始模拟核查”；运行前不展示结果。原型不解析所选文件字节。
- 加载中：短暂模拟进度，禁用运行按钮，不暗示真实解析。生产长任务需要进度／取消。
- 已完成：完整基准计数、筛选、搜索、选择与详情。模拟列表先列未配置、已划线、描述变化，再列普通已配置；默认“全部”，提供“仅异常”快捷入口。
- 不支持选择：提示仅接受 `.docx`；拒绝同时选择多个文件。扩展名只是原型输入门槛，不是真实格式验证。
- 搜索／筛选无结果：明确空结果和清除操作，不保留旧详情。
- 基准已编辑：清除结果，要求重新核查。刷新重置浏览器会话修改，并明确提示。
- 生产解析失败：给出恢复／重选提示，不显示全部未配置。受保护、损坏、超大文件有规格要求，但原型没有模拟真实解析结论。

## 生产结果与详情行为

筛选不改变汇总计数。提供全部／已配置／未配置／已划线／待人工核查，以及仅异常；搜索编号、名称、分类和预期文字。未配置和已划线使用不同文字、符号，不只依赖颜色。选中高亮不能像工程验收通过。

详情展示规范名称／分类／编号、预期要求、实际文字、匹配方法及其匹配范围、可选且单独标注的分数、差异和来源。已配置但不同的项保留 CONFIGURED，增加“描述有差异”，不用“通过”措辞。`2s → 3s` 与完整的两段描述同时显示。生产 MVP 提供基本的受支持文本比较，不确定时 NOT_COMPARED；增强 diff 留在 V0.2。浏览器 diff 是固定 token 替换，不是通用引擎。

未配置详情说明已检查范围内没有对应证据，不虚构位置。已划线详情对实际文字显示删除线和状态标签，预期文字不划掉。上下文显示前／当前／后块及表格坐标；它是重建摘录，不是 Word 页面，坐标从 1 开始。重复证据列出全部出现位置，并允许选择查看。正常／删除线并存、部分／未知格式、有效参数冲突显示“待人工核查”、原因和空 CheckStatus。一致的正常出现可以仍是已配置。首个位置只决定初始显示，不代表证据权威性。

## 检查项管理

紧凑表格包含编号／名称／分类／预期描述／启用状态／操作。新增／编辑对话框包括 code、name、匹配短语、category、expectedDescription、每行一个 alias、notes、enabled。code/name/detectionPhrase 必填，code 唯一；预期描述可空并解释含义。生产需提示相似名称／别名重叠；原型拒绝完全重复名称。禁用可恢复，删除前确认。保存关闭对话框、恢复焦点并使结果失效；取消／Escape 丢弃编辑。

生产修改在当前 Windows 用户本地持久保存；浏览器原型仍为会话级并保留提示。“检测短语”与“功能名称”是独立字段，别名为明确的替代短语，不能把推测出来的短语预填成已批准值。

## 键盘与鼠标

原生按钮、带标签字段和清晰焦点；Tab/Shift+Tab 可遍历操作。对话框限制焦点范围，Escape 关闭。结果行 Arrow Up/Down 移动选择，Enter 激活。结果显示时 Ctrl+F（Mac 预览 Cmd+F）聚焦搜索；编辑对话框打开时不拦截。拖放和选择共用校验。工具提示只能补充信息，不能是证据解释的唯一入口。

## 视觉方向

Operate 模式：办公场景浅色中性背景，深色正文，蓝色操作／选择；绿色已配置、红色未配置、棕色删除／差异，保持对比度。系统字体，包含 Microsoft YaHei/PingFang 后备；正文 13–14px、控件 28–36px；边角方正或轻微圆角、表格分隔线；不加渐变或装饰动画。长中文描述换行，不藏进 tooltip。默认桌面 1440×900，检查 1024 宽度及窄屏后备。不依赖外部字体、素材或网络。

## 原型审查路径

1. 从空状态选择 DOCX（仅文件名）或加载示例，然后模拟核查。
2. 确认 11 项：8 已配置、2 未配置、1 已划线、1 独立描述差异。
3. 分别筛选状态，搜索 `2门`，选择 DR-006 检查 `2s → 3s` 与表格上下文。
4. 选择 DR-004 查看删除线，DR-003 查看没有证据的状态。
5. 查看 DR-002 NORMALIZED、DR-009 ALIAS 的解释，不制造置信度。
6. 在管理界面新增／编辑／禁用／删除，取消编辑，确认结果失效和重新核查。
7. 检查键盘、不支持扩展名、无搜索结果与替换选择仍然清晰。

## 原型之外的已确认生产状态

- 待人工核查：status 为空，resolution=UNRESOLVED，显示原因和全部证据，不显示置信度徽标、不回退为未配置。计入汇总／筛选。启用总数 = 已配置 + 未配置 + 已划线 + 待人工核查；描述差异是独立计数，不参与该求和。
- 仅异常包含未配置、已划线、待人工核查和描述差异。建议初始顺序为待人工核查、未配置、已划线、描述不同的已配置、其他已配置；组内保持稳定基准顺序。UI 排序不表示证据优先级。
- 检查范围受限（coverage=LIMITED）：持续显示运行级提示与排除／不支持内容，不混入文档状态。汇总说明已检查范围。范围不含自动跨段落／单元格连接和不支持的 Word 部分；无法安全提取则失败，不作受限成功。
- 没有预期描述时显示“未比较描述”；别名命中但没有经验证的比较也如此。单处明确功能参数不同为已配置＋差异，多处有效值冲突为待人工核查。
- 加载／进度／取消时保持 UI 可用；取消／失败不显示成功最终计数。文档／基准变化使结果失效。访问拒绝、文件锁定、写入失败提供可操作恢复提示。
- 首次启动／部署不出现提权要求，不要求用户安装 Python/Qt。采用验证通过的便携包或允许的用户级安装程序；说明数据位置并在替换时保留基准。报告 IT 策略阻止，不建议提升权限或绕过策略。

## Qt Widgets 实现方向

使用主窗口、splitter 分栏、结果／基准 item views，以及标准文件选择和编辑对话框。这是选定工具包的实现方向，不是可复用控件框架。匹配／解析放在 widgets 外。在两类 Windows 上检查键盘焦点、中文输入、长标签和 DPI。紧凑浏览器布局是视觉参考，不要求在 Qt 内嵌 HTML。

## 已确认的 Python 3.8 与完全离线环境

用户说明：公司电脑目前安装 **Python 3.8**，能否升级未知。这是现有环境事实，不表示已经选择应用／构建运行时版本。保留该安装及其 PATH／文件关联，不作修改。目标仍为 **Windows 10 和 Windows 11 x64**，使用者**没有管理员／安装权限**。**首次分发、解压／安装、首次启动和正常核查必须完全离线。**

计划的自包含包须携带经过验证的 Python／Qt／原生依赖，不调用电脑中的 `python`，不要求目标机执行 `pip install`、在线激活或下载。S3 必须断网、无缓存前置依赖，分别验证与现有 Python 3.8 共存且不改动它，以及未安装 Python 的干净电脑。目前没有分发包通过这些检查。

开发／构建环境是否可用仍是独立未决项：确认能否在不改变公司安装的条件下，使用获准的隔离／较新解释器及 Windows 构建机。不能认为 Python 3.8 的 `venv` 会升级解释器。如果唯一允许的构建／运行时就是 3.8，应先评估准确兼容依赖组合及维护影响，不能悄悄锁定旧包或改变技术栈。完全离线交付不代表已经确认构建机本身能否联网；需要单独记录，并在必要时准备离线构建依赖。
